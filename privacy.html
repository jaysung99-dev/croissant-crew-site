可頌上片助手

隱私權政策

最後更新：2026 年 11 月 18 日

本政策說明「可頌上片助手」（以下稱本工具）如何處理透過 Google 帳戶授權取得的資料。本工具只供「可頌尬煉乳」實況主本人使用，用來管理自己的 YouTube 頻道。

我們存取哪些 Google 資料

  • YouTube 影片上傳權限（youtube.upload）：把本人核定過的影片、標題、說明與標籤上傳到本人的頻道。
  • YouTube 頻道與影片的唯讀資訊：辨認上傳的目標頻道，並讀取已上傳影片的公開成效數字（例如觀看數）。

資料如何使用

上述資料只用在上傳影片與檢視成效。本工具不會用 Google 使用者資料投放廣告，不會出售或轉讓，也不會用來訓練通用的人工智慧或機器學習模型。

資料如何保存

  • 授權權杖經加密後只保存在實況主本人的電腦上，不上傳到任何雲端伺服器。
  • 影片檔與文案草稿保存在同一台電腦上。
  • 本工具沒有對外開放的伺服器，也不蒐集其他人的資料。

資料分享

除了把影片上傳到 YouTube 本身之外，本工具不會把 Google 使用者資料分享給任何第三方。

撤銷授權與刪除資料

你可以隨時到 Google 帳戶的「第三方應用程式與服務」移除本工具的存取權。撤銷後，本機保存的權杖即失效；實況主也會一併刪除本機的加密權杖。

Google API 服務使用者資料政策

本工具使用與轉移從 Google API 取得的資訊時，會遵守 Google API 服務使用者資料政策，包括「有限使用」規定。本工具也使用 YouTube API 服務，請一併參閱 YouTube 服務條款與 Google 隱私權政策。
